Outpainting with FLUX.2 Klein

Use Settings → Photo Edge Expansion → FLUX.2 Klein to generate extra surroundings before Apple Photos Reframe animates the photo. Both models run on your Mac. Photos are not uploaded to a model service.

Allow several minutes per new photo. Expanded stills are cached across launches, so changing motion or zoom does not require another outpainting pass. Start with a small amount of extra area. Generated scenery can contain visible seams or invented details.

First-time setup

Enable Expand photo edges, select FLUX.2 Klein · MLX, and press Play. The app installs a verified Python runtime, packages, and pinned models automatically. You can also choose Settings → Models & Downloads → Download / Check Models before playback. No Python, Homebrew, or developer tools need to be installed.

Allow approximately 16 GB of free space, including roughly 10 GB of model downloads, the Python environment, and processing space. Setup shows progress and supports cancellation and retry. After setup, model inference runs offline.

Existing and custom installations

The app checks an existing registered runtime before downloading anything. To supply your own installation, expand Advanced runtime settings, click Choose…, and select the environment containing bin/python and mlx-gen. The required model snapshots below must already be downloaded. Custom environments are not modified. Choose Reset to Automatic to return to managed setup.

Advanced Terminal setup

If you prefer to supply your own Python 3.12, run the bundled installer. Replace the app location with where you saved it:

python3.12 "/path/to/Spatial Slideshow.app/Contents/Resources/setup_klein.py"

Or from a source checkout:

python3.12 Scripts/setup_klein.py

To register a compatible existing environment without downloading a second copy:

python3 Scripts/setup_klein.py --use-existing "/path/to/environment/bin/python"

The installer registers the runtime in ~/Library/Application Support/Photos Spatial Slideshow/Klein Runtime/. If you installed it while the app was open, reopen Settings. Playback always checks the current registration.

Models and runtime

This option uses FLUX.2 Klein Base 4B, 8-bit, fal’s outpainting adapter, and mlx-gen 0.38.0. The installer pins the model revisions used by the app. Weights and Python packages are installed separately and are not bundled with Spatial Slideshow.

Apple Fast Clean Up remains the default expansion option. Expansion itself is off for new users. Choosing FLUX changes only the edge generation step; 3D animation still uses the actual Apple Photos Reframe model.
