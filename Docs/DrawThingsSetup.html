Outpainting with Draw Things

Select Settings → Photo Edge Expansion → Draw Things · FLUX.2 Klein to extend photos with the local Draw Things engine. The expanded photo then goes through the actual Apple Photos Reframe model for 3D motion.

New photos require processing; completed expanded stills are saved for reuse across launches and changes to motion or zoom. Generated borders can contain invented details or visible joins. The original photo’s interior is restored at full resolution.

First-time setup

You need an Apple Silicon Mac and Python 3.12. The pinned models total 8.63 GB (8.04 GiB); the server and model manager add about 0.51 GB. Allow approximately 16 GB of free space for a fresh installation, including Python packages and the first-run model conversion. Setup reserves 5 GiB for that conversion because Draw Things briefly creates another large tensor file before compacting the original. An already converted installation needs only the normal 2 GiB of working space. The installer checks space before downloading and does not delete existing models or photo caches.

In Terminal, run the installer bundled with your app, replacing the app path with its actual location:

python3.12 "/path/to/Spatial Slideshow.app/Contents/Resources/setup_drawthings.py"

Or run from a source checkout:

python3.12 Scripts/setup_drawthings.py

To put the model files on another drive, add:

--models-directory "/Volumes/Your Drive/Spatial Slideshow Models"

When setup finishes, reopen Settings, enable edge expansion, and choose the Draw Things option. Setup registers this runtime separately and does not change your selected backend or slideshow preferences.

Reuse an existing installation

You can reuse a compatible Python 3.12 environment, official downloaded binaries, and a model folder. The two binaries are checksum-verified and copied into the managed runtime. Python and the supplied model folder remain in their existing locations, so keep them available.

python3 Scripts/setup_drawthings.py \
  --use-existing "/path/to/environment/bin/python" \
  --server-binary "/path/to/gRPCServerCLI-macOS" \
  --cli-binary "/path/to/draw-things-cli" \
  --models-directory "/path/to/Models" \
  --no-download

For an app installation, replace Scripts/setup_drawthings.py with the bundled installer path. --no-download verifies that everything is already present and prevents network downloads. Omit it to fetch missing binaries or models. --use-existing never changes packages in the environment you provide.

Local processing

The app uses a dedicated local server bound to 127.0.0.1:7863, with the server’s default TLS enabled. It is not exposed to your network. Setup does not start the server or install a background login service. Model generation stays on your Mac; photos are not uploaded to a cloud service.

Runtime registration is stored at ~/Library/Application Support/Photos Spatial Slideshow/Draw Things Runtime/runtime.json. Default binaries, Python environment, and models live in the same folder. Existing Apple Fast Clean Up and MLX backends remain available.

Pinned components

The installer uses the official Draw Things v26.0910.1 release and drawthings-py 0.4.0. Models and runtime software are installed separately; they are not included in Spatial Slideshow’s app download.

  • flux_2_klein_4b_i8x.ckpt
  • qwen_3_4b_q8p.ckpt
  • flux_2_vae_f16.ckpt

After its first use, Draw Things may split the Qwen file into a small .ckpt and a large .ckpt-tensordata file. Keep both. Setup recognizes and verifies this converted pair, so running setup again does not download another copy.

If setup reports a checksum mismatch, it leaves the existing file in place. Choose a different model directory or move the named file aside yourself, then retry. If port 7863 is already in use, stop the conflicting local process before starting this backend.
